# transport-tirana/gtfs

This is the Urbani GTFS feed as ingested by TIR.

The original source is available from [urbani.tirana.al](https://urbani.tirana.al).

A `feed.zip` is available from GitHub Releases and is automatically built on commit.

> The current feed is valid from `2026-01-01` to `2026-12-31`.
